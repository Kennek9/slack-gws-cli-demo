# 合并后的协作方式

[网页演示](https://kennek9.github.io/slack-gws-cli-demo/) · [中英 Tada 指南](https://docs.google.com/document/d/1BOI80LqwMVBZFWf1ZwdUfLRzD_eu_ZL5rbjGNcDmmO4/edit)

约 6 分钟，11 页，分三层，前一层是后一层的基础：

1. 找到彼此：中国同事至少开放北京时间 08:00–10:00 或 22:00–24:00 中的一段，并在 Google 日历标明工作时间；页面列出美西、英国、墨西哥和巴西对应的时间。
2. 找到信息：先区分 Slack 中的 Tada 与 AI Agent 使用的 Google Workspace CLI，再介绍怎么在 Slack 问 Tada 查找已接入的公司文档，以及如何让业务讨论里的信息更容易找到。
3. 使用 Google Workspace CLI：先介绍 CLI 如何让 AI Agent 操作 Google 应用，再用自然语言完成工作：将与 AI 讨论的结果写入 Google 文档并继续修改，以及核对多语言文案并起草回复。两个场景均参考实际工作，并去掉了敏感细节。

演示标题使用英文，正文保留中英对照。直接在浏览器打开 `index.html`。左右键切页，F 全屏。讲者快捷键（页面上不显示按钮）：C 在中英对照、英文、中文之间切换，R 重播动画，N 打开讲者备注。最后一页的按钮打开安装说明。工作时间按打开页面时的北京日期换算。

公开网页使用脱敏示例；Tada 演示页展示 Slack 真实回复，中英文回复顺序调整为英文在前，来源链接已隐藏。Google Doc 教程需用 Glorify 公司账号打开。
