# Slack + Google Workspace CLI 演示

[打开网页预览](https://kennek9.github.io/slack-gws-cli-demo/) · [编辑网页源码](index.html)

直接用浏览器打开 `index.html` 也可以预览。左右方向键切幕，F 全屏。讲者快捷键（页面上不显示按钮）：C 切换中英对照，R 重播动画，N 打开讲者备注。公开演示采用匿名示例和链接占位符。

## 复制给另一位 AI 的提示词

```text
请优化这份约 5 分钟的团队 onboarding 演示。先打开网页，走完 A/B 点选和复制问法，再直接修改 index.html。演示对象是第一次接触 Slack CLI 和 Google Workspace CLI 的研发、产品、内容和增长同事。约六七成同事讲中文，其余讲英文。

大家看完要能用在手头的事上。开场先给一个认得出的场景，例如评审快开始了，同事来问这一版的规则。演出以前要去哪几处翻资料，然后展示我在平时用的 AI Agent 里贴哪两个链接、输入哪句话、拿到什么能用的结果。明确 slack 读群里的更新，gws 读 Google 文档，AI Agent 对照后给出答案和来源。把完整问法和安装、登录说明留在备注或可复制入口。

用一个主案例讲透，并保留能点的 A/B。A 像「帮我总结一下好友请求」，B 像「同事正在问这版收到请求在哪看。用 slack 读群里更新，用 gws 对照规格，给我一句能发的回复」。展示两种问法各得到什么。也点出找一条已知消息可以直接搜 Slack，开数据权限可以用 slack 找历史上下文，再联系看板负责人。每个例子都让人看见它解决的工作，以及具体交付物。

如果有授权的团队 Slack 或 Lark 资料，优先从各部门反复出现的问题选案例，同一件事的重复追问合并。只有在统计口径和覆盖范围清楚时才说「最高频」。公开网页使用匿名示例。统计页已经移除，统计过程和来源可以放进备注。

画面尽量少字，语言像同事平时聊天。英文和中文放在同一层级、用同字号。用浅奶油色、淡杏色和少量橙色。可参考 Apple 和 Airbnb 发布会的留白和镜头节奏。让动画依次亮出工作来信、资料、输入和可用结果。演示无声，由讲者推进。产品称呼统一写 AI Agent。

完成后检查 16:9 投屏，验证 A/B、复制问法、左右键、全屏和中英切换。看前一分钟的人应该能说出什么时候用、要贴什么、该怎么问，以及会拿到什么。交付改好的页面和简短的改动说明。
```
