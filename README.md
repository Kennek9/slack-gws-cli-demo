# 合并后的协作方式

[网页演示](https://kennek9.github.io/slack-gws-cli-demo/) · [中英 Tada 指南](https://docs.google.com/document/d/1BOI80LqwMVBZFWf1ZwdUfLRzD_eu_ZL5rbjGNcDmmO4/edit)

约 6 分钟，10 页，分三层，前一层是后一层的基础：

1. 找到彼此：中国同事至少开放北京时间 08:00–10:00 或 22:00–24:00 中的一段，并在 Google 日历标明工作时间；页面列出美西、英国、墨西哥和巴西对应的时间。
2. 找到信息：怎么用 Tada，业务讨论尽量放公开频道，以及个人 Agent 和 Tada 分别能搜到什么。
3. 用 AI 干活：连接 Google、连接 Slack、两边一起完成一件事。

直接在浏览器打开 `index.html`。左右键切页，F 全屏。讲者快捷键（页面上不显示按钮）：C 在中英对照、英文、中文之间切换，R 重播动画，N 打开讲者备注和可复制问法。最后一页的按钮打开安装步骤和问法。工作时间按打开页面时的北京日期换算。

公开网页使用脱敏示例；Tada 检索页是真实检索结果，已隐去链接。Google Doc 教程需用 Glorify 公司账号打开。
