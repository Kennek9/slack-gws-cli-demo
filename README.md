# 合并后的协作方式

[网页演示](https://kennek9.github.io/slack-gws-cli-demo/) · [中英 Tada 指南](https://docs.google.com/document/d/1BOI80LqwMVBZFWf1ZwdUfLRzD_eu_ZL5rbjGNcDmmO4/edit)

约 6 分半钟，8 页。先标明跨国协作时间，再用 Slack 里的 Tada 查公司资料，最后展示个人 AI Agent 如何用 Slack 和 Google 产出一份带来源的文档。

直接在浏览器打开 `index.html`。左右键切页，F 全屏，C 在中英对照、英文和中文之间切换，R 重显本页，N 打开讲者备注和可复制问法。工作时间按打开页面时的北京日期换算。

公开网页使用脱敏示例。Google Doc 教程需用 Glorify 公司账号打开。线上 Tada 演示使用获准的测试频道，由讲者本人演示。
